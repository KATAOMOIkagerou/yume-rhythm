# 桌宠节奏师源码重构说明

本次直接修改现有工程，沿用原有音频检测器、节拍动画、活动模式、随机事件情境矩阵和待办存储。

## 模块一：窗口与全局设置

### 透明与锁定

文件：`electron/main.cjs`、`electron/preload.cjs`、`src/App.tsx`、`src/styles.css`。

主窗口原为普通的 1120×780 浅色窗口，修改为 540×590 透明无边框窗口。网页背景、角色舞台卡片和场景背景绘制同步移除，避免仅设置窗口透明而网页仍不透明。拖动区域采用原生窗口拖动，锁定时同时禁止拖动和开启点击穿透。

```diff
- width: 1120, height: 780, backgroundColor: '#fdf4f8'
+ width: 540, height: 590, resizable: false, frame: false,
+ transparent: true, backgroundColor: '#00000000', alwaysOnTop: true
```

```js
function setLocked(value) {
  locked = Boolean(value);
  petWindow.setMovable(!locked);
  petWindow.setIgnoreMouseEvents(locked, { forward: true });
  petWindow.webContents.send('pet:locked', locked);
  // 同时刷新托盘菜单
}
```

状态：主进程 `locked` 是真实窗口状态来源；React 的 `petLocked` 通过受限桥接同步。按钮发出 `pet:set-locked`，主进程验证发送者后修改窗口；`pet:locked` 同步快捷键和托盘导致的变化。不能只改 React 样式，否则鼠标仍被窗口拦截。

锁定后可从独立控制台「设置」、托盘或 `Ctrl＋Alt＋L` 解锁。托盘与 `Ctrl＋Alt＋C` 可随时重新显示控制台，避免窗口穿透后无法操作。快捷键被占用时仍保留托盘入口。


### 随机触发与恢复

文件：`src/App.tsx`、`src/gui/EmotionTab.tsx`；移除 `useCharacterEvents.ts` 内原先固定 8.5～14.5 秒随机触发器，保留眨眼和情境判断，避免两套定时器互相争抢。

```tsx
const eligibleExpressions = expressions.filter((entry) => entry.random &&
  (!entry.event || isRandomEventAllowed(entry.event, activityMode, musicRunning, eventSwitches)));

const entry = pool[Math.floor(Math.random() * pool.length)];
setRandomExpression(entry);
randomEndRef.current = window.setTimeout(() => setRandomExpression(null), entry.durationMs);
// 触发间隔来自 settings.randomIntervalSeconds * 1000。
```

状态：`expressions` 为加载的配置；`selectedId` 为手动选项；`baseId` 保留整体基础表情；`randomExpression` 为临时随机状态。配置、开关或情境变化时清理随机定时器；随机结束清空临时状态并恢复手动选择，不覆盖用户选择。音乐期间过滤打瞌睡，保留原有休闲／自习／音乐开关约束。

### 整体与局部分层

文件：`src/character/DeskCharacterScene.tsx`。

```tsx
const base = baseExpression ?? (expression?.type === 'base' ? expression : null);
const accessory = expression?.type === 'accessory' ? expression.resources : undefined;
const exprDef = base?.resources ?? manifest.expressions[emotion];
const mouthFile = accessory?.mouth ?? exprDef.mouth ?? manifest.expressions.neutral.mouth;
```

`base` 配置完整动画时直接替换原分层主体；配置眼嘴时仍使用原主体并互斥替换五官。`accessory` 保留所选基础表情，仅替换有配置的局部图层或追加透明动画；叠加层继承头部运动。完整动画自带五官，应使用透明叠加配件，而不是分层眼嘴替换。

### 再次点击恢复自然

文件：`src/App.tsx`。

```tsx
const nextId = expression?.id === id ? 'neutral' : id;
```

## 模块四：双向计时与结束音效

文件：新增 `src/state/timer.ts`；修改 `src/App.tsx`、`src/gui/StatusTab.tsx` 和设置页。

```ts
export type TimerMode = 'countdown' | 'stopwatch';
export function timerValue(mode: TimerMode, anchor: number, now: number): number {
  return Math.max(0, mode === 'countdown' ? anchor - now : now - anchor);
}
```

```tsx
const value = timerState === 'paused' ? remainingMs : timerMode === 'countdown' ? duration : 0;
timerEndAtRef.current = timerMode === 'countdown' ? Date.now() + value : Date.now() - value;
setTimerState('running');
```

状态：`timerMode` 区分方向；`timerState` 仍为原有未启动／运行／暂停／完成；`remainingMs` 在倒计时表示剩余时间、在正计时表示已用时间；`timerEndAtRef` 在倒计时保存结束时刻、在正计时保存开始锚点。暂停时结算时间，继续时重新建立锚点。使用墙钟差值而非累计递减，避免窗口隐藏或回调延迟产生漂移。运行或暂停时禁止切换方向，须重置后切换。

```tsx
if (timerModeRef.current === 'countdown' && left <= 0) {
  timerEndAtRef.current = null;
  setTimerState('completed');
  if (soundEnabledRef.current) void soundRef.current?.play().catch(() => {});
}
```

完成提示音通过独立 `AudioContext` 合成三音，不需要额外音频文件；开始计时的用户操作中预先初始化音频上下文。结束锚点清空后不重复触发。全局 `settings.endSoundEnabled` 控制声音，正计时不会自动结束或鸣响。

## 全局中文化与验证

除上述页面外，`Modals.tsx`、`TodoDrawer.tsx` 中的确认、取消、继续、清单名称、保存清单全部改为中文；快捷键字母、资源文件名和内部代码标识保留原样。打包生成的使用说明和 README 同步更新。

```powershell
npm run build
npm run verify:features
npm run verify:desktop
```

`verify:features` 包含中文界面静态扫描、双向计时和暂停恢复、配置校验与文件检查、音效生成以及冻结音频代码校验。`verify:desktop` 实际启动双窗口，覆盖透明、锁定、关闭后继续计时、配置自动生成选项、整体动画分支、配件保留基础表情、随机恢复、结束音效开关、待办保存、真实音频文件的节拍检测与停止快捷键。

音效触发和开关在桌面回归中使用模拟音频接口验证，不能代替用户声卡上的主观试听。历史安装包专用 `verify:audio` 需要提供 `BASELINE_ASAR_PATH`；当前机器没有该历史文件，改用仓库基准对比确认本次未改音频核心及媒体权限业务逻辑。
