# 角色包格式（v2）

一个角色包是一个目录，放在程序同级的 `characters\<id>\`（内置）或 `%APPDATA%\韵梦桌伴\characters\<id>\`（用户安装）下。目录名就是角色 id，只能用小写字母、数字、`-`、`_`。

```
characters/sakura/
  character.json     角色、图层、动作、特效
  expressions.json   表情
  *.png              图片
```

画手的工作流：在同一张画布上分层画好，每层按**画布原尺寸**导出为透明 PNG（例如 800×800，空白处透明）。程序加载时会自动裁掉空白，不用手动裁。

---

## 1. character.json

```jsonc
{
  "format": 2,
  "id": "sakura",                       // 必须与目录名一致
  "name": "二次元学霸少女·樱音",
  "version": "1.0.0",
  "author": "",
  "canvas": { "width": 800, "height": 800 },
  "viewport": { "x": 30, "y": 0, "width": 740, "height": 750 },   // 桌宠窗口显示画布的哪一块
  "display_scale": 0.675,               // 缩放 100% 时，画布 1 像素显示为多少屏幕像素
  "rigs": {
    "body": { "pivot": [400, 704] },    // 身体呼吸、摇摆的中心
    "head": { "pivot": [400, 452] }     // 头部点头、歪头的中心
  },
  "motion": { "nod_amplitude": 1.0, "nod_tilt": 1.0, "breath": 1.0, "sway": 1.0 },
  "layers": [ /* 从下到上，见第 2 节 */ ],
  "blink": { "image": "eyes_blink.png", "min_interval_ms": 2400, "max_interval_ms": 5200, "duration_ms": 150 },
  "effects": { "beat_ring": { /* 见第 4 节 */ }, "notes": { /* 见第 4 节 */ } }
}
```

- 坐标一律用**画布像素**。
- `viewport` 之外的内容不显示。节拍光环和音符会飘出角色范围，要给它们留出空间。
- `motion` 是动作幅度倍率，1.0 为默认。动作模型本身（弹簧、阻尼）在程序里，角色包只调幅度。
- `blink` 可省略，省略则不眨眼。

## 2. 图层

`layers` 从下到上排列。每层二选一：固定图片 `image`，或由表情决定的槽位 `slot`。

| 字段 | 取值 | 说明 |
|---|---|---|
| `image` | 文件名 | 固定图片 |
| `slot` | `eyes` / `mouth` / `overlay` | 眼、嘴取自当前表情；`overlay` 是附加表情的特效（泡泡、ZZZ 等） |
| `rig` | `root`（默认）/ `body` / `head` | 跟随哪个部位运动。`root` 不动 |
| `when` | `{ "activity": "study" \| "chill", "music": bool, "timer": bool }` | 显示条件，可组合，省略表示总是显示 |
| `effect` | `glow` / `float` | `glow`：柔和发光脉动（计时钟）；`float`：上下漂浮（表情特效） |

`when` 的含义：`activity` 是当前活动模式；`music` 是否正在放音乐；`timer` 学习计时是否在运行。

示例：

```json
{ "image": "head_headphones.png", "rig": "head", "when": { "music": true } },
{ "image": "prop_computer_on.png", "when": { "activity": "study" } },
{ "image": "prop_timer_clock.png", "when": { "timer": true }, "effect": "glow" },
{ "slot": "overlay", "rig": "head", "effect": "float" }
```

## 3. expressions.json

角色的表情目录。

```json
{
  "version": 1,
  "expressions": [
    { "id": "neutral", "name": "自然", "type": "base",
      "resources": { "eyes": "eyes_neutral.png", "mouth": "mouth_neutral.png" },
      "durationMs": 3200, "random": false },
    { "id": "happy", "name": "开心", "type": "base", "blink": false,
      "resources": { "eyes": "eyes_happy.png", "mouth": "mouth_happy.png" },
      "durationMs": 4000, "random": true },
    { "id": "doze", "name": "打瞌睡", "type": "accessory", "event": "doze",
      "resources": { "eyes": "eyes_doze.png", "mouth": "mouth_doze.png", "overlay": "fx_doze_zzz.png" },
      "durationMs": 3200, "random": true }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `type` | `base`：基础表情，替换眼和嘴。`accessory`：附加表情，叠加在当前基础表情上，可替换眼、嘴并加 `overlay` 特效 |
| `resources.animation` | 基础表情：用这一张整图替换整个角色（跟随头部运动）。附加表情：作为特效图 |
| `event` | `doze` / `think` / `shock` / `love`。有事件的表情受控制台"随机事件"开关约束 |
| `durationMs` | 作为随机表情时显示多久，100–600000 |
| `random` | 是否参与随机表情 |
| `blink` | 默认 `true`。设为 `false` 时，这个基础表情不眨眼（比如笑眯眯的眼睛） |

附加表情替换了眼睛时，不会眨眼。

## 4. 特效

```jsonc
"beat_ring": {                 // 每拍从角色身后扩散的圆环
  "center": [400, 340], "radius": [140, 325], "width": [12, 1.5],
  "color": "#c084fc", "opacity": 0.42, "duration_ms": 620
},
"notes": {                     // 每拍飘出的音符
  "images": ["note_1.png", "note_2.png", "note_3.png", "note_4.png", "note_5.png"],
  "area": { "x": 240, "y": 128, "width": 320, "height": 80 },   // 出生区域
  "size": 36, "rise": 110, "drift": 50,                         // 画布像素
  "hue": [190, 320], "chance": 0.85, "max": 12, "duration_ms": 1500
}
```

音符图片是**白色**的字形，程序会按 `hue` 范围随机着色并加白色光晕。两项都可以省略。

## 5. 校验规则

加载时逐条检查，任何一条不满足都会给出中文错误，并继续显示之前的角色：

1. `format` 必须是 2，`id` 与目录名一致且只含小写字母、数字、`-`、`_`。
2. 所有文件名必须是包内的相对路径：不能以 `/` 开头，不能含 `..`、`\`、`:`。
3. 图层图片必须与 `canvas` 同尺寸。
4. 表情 id 不能重复，必须包含 `neutral`，`neutral` 必须有眼和嘴（或 `animation`）。
5. `durationMs` 在 100–600000 之间。
6. 引用的图片必须存在且能解码。
7. 单张图片不超过 4096×4096，图片总数不超过 200。

## 6. 自定义表情目录

用户通过控制台「表情编辑器」新建或编辑的自定义表情保存在 `%APPDATA%\韵梦桌伴\custom_expressions\<id>\` 下，与内置角色包分离，互不覆盖：

```
%APPDATA%\韵梦桌伴\custom_expressions\<id>\
  expressions.json   自定义表情列表（与角色包第 3 节同构）
  custom-1_eyes.png  复制并规范化命名后的分层 PNG
  custom-1_mouth.png
  custom-1_overlay.png
```

- 读取角色包时程序会尝试加载对应角色的自定义表情目录；其中的相对文件名在加载时自动加上 `custom/` 前缀，避免与内置素材文件名冲突。
- 校验规则：
  1. `id` 不能与内置表情或其他自定义表情重复；
  2. `durationMs` 在 100–600000 之间；
  3. 一级表情（`base`）必须同时包含 `eyes` 和 `mouth`；二级表情（`accessory`）`eyes` / `mouth` / `overlay` 至少包含一种资源；
  4. 所有图片必须为与角色画布（如 800×800）同尺寸的 PNG，总图片数不超过 200。
- 若自定义目录解析或校验失败，会舍弃全部自定义表情并把中文提示写入 `custom_warning`，内置角色包照常加载显示。
