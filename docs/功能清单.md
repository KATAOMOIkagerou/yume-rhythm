# 功能清单

本文列出韵梦桌伴（`yume-rhythm`）的全部功能和规则。代码注释里的"功能清单第 N 节"指本文的节号。

- 业务规则的实现在 `crates/core`，场景测试在 `crates/core/src/update/tests.rs`。
- 画面相关的参数（位置、幅度、特效）写在角色包里，格式见 [角色包格式](角色包格式.md)。

---

## 1. 桌宠窗口

- 透明、无边框、置顶的分层窗口，不抢焦点，不在任务栏和 Alt+Tab 中出现。
- 逐像素点击：只有角色不透明的像素响应鼠标，透明处的点击落到下面的窗口。
- 拖动：按住左键拖动，松开后保存位置。
  - 位置以窗口底边中点为锚点，改变大小时角色脚下不动。
  - 启动时若保存的位置不在任何显示器上，拉回可见区域。
- 单击：打开控制台。
- 右键菜单：打开控制台、开始／停止听歌、锁定桌宠、退出。
- 锁定：整个窗口点击穿透、不能拖动。
  - 可以从托盘、控制台设置页或 Ctrl+Alt+L 解除。
  - 锁定状态不保存，重启后解除。
- 拖入文件：把音频文件拖到桌宠身上，循环播放并跟拍（见第 9 节）。
- 大小：50%–200%，按 5% 取整，并跟随显示器 DPI。
- 透明度：30%–100%，按 5% 取整，默认 100%，会保存。
- 窗口标题：`yume-rhythm`。
- 全屏时隐藏（默认开）：前台有全屏程序时隐藏桌宠，退出全屏后恢复。
- 帧率：跟拍时 60 fps，其余 30 fps；画面没有可见变化的帧不重画。
- 单实例：再次启动时不会开第二份，而是让已运行的那份显示控制台并带到最前面。

## 2. 控制台窗口

- 普通窗口，400×680，最小 360×520，窗口标题 `yume-rhythm`，内部中文品牌名「韵梦桌伴」。
- 透明度：控制台窗口整体透明度 40%–100%，按 5% 取整，默认 100%，会保存；背景透明度与卡片透明度 0%–100% 独立可调，按 5% 取整，默认 100%，会保存。
- 外观（背景与强调色独立设置）：
  - 背景模式：浅色（白）/ 深色（黑）/ 自定义 HEX，卡片、边框与文字对比度按背景亮度自动推导；从深色或浅色切换到自定义时，在输入有效 HEX 前保留原底色，输入并应用后按新颜色更新。
  - 背景图片：支持导入本地 PNG / JPG 图片作为控制台背景（铺满裁切），上方覆盖背景色遮罩（浓度 20%–95% 可调），支持清除，会保存。
  - 强调色：5 套内置预设（樱花粉、晴空蓝、丁香紫、落日橘、薄荷绿）与第 6 个等宽「自定义」按钮（3×2 网格），仅点击「自定义」时展开 6 位 HEX 输入框与「应用」「清除」按钮，会保存。
  - 界面圆角：支持「圆角」（默认 14px）、「关闭圆角」（0px）、「自定义」（0–28px 滑块调节），会保存。
- 字体与字号：中文字体（上方下拉框，默认微软雅黑 UI）与英文字体（下方下拉框，默认 Segoe UI）分开选择，英文字体查找优先级高于中文字体（英文/数字优先走英文字体，中文回落中文字体）；支持字号大小（11–18px，默认 13px）、导入本地 `.ttf`/`.otf` 字体文件与一键恢复默认，会保存。
- 四个标签页：专注、表情、音乐、设置。
- 顶部显示角色名和音乐状态：未在听歌、同步中，或当前 BPM。
- 关闭窗口只是隐藏，计时和音频继续。
- 首次运行时自动打开。

## 3. 快捷键与托盘

- 全部 6 个快捷键支持在设置页点击录制自定义、冲突检查、冲突/占用提示与一键恢复默认（会保存）：
  - 控制台内快捷键（输入框有焦点时不触发）：
    - 开始／停止听歌：默认空格（开始时重放上一次的音源，默认系统声音）。
    - 停止听歌：默认 Q。
    - 隐藏控制台：默认 H。
  - 全局快捷键（必须包含修饰键，或留空禁用）：
    - 显示／隐藏控制台：默认 Ctrl+Alt+C。
    - 切换锁定：默认 Ctrl+Alt+L。
    - 全局开始／停止听歌：默认未设置（可选录制）。
  - 全局快捷键被其他程序占用时在设置页标出提示，托盘菜单仍可用。
- 托盘图标（提示文案「韵梦桌伴」）：
  - 双击：打开控制台。
  - 菜单：打开控制台、开始／停止听歌、锁定桌宠（勾选）、开机自动启动（勾选）、退出。

## 4. 学习计时

- 两种方向：倒计时、正计时。运行或暂停时不能切换方向。
- 倒计时时长：1–999 分钟，默认 25 分钟，另有 15／25／45／60 快捷按钮。时长和方向会保存。
- 按墙钟时间戳计时：后台不漂移，电脑休眠醒来后已经走过休眠的时长。
- 开始计时会切换到自习（见第 5 节）。
- 暂停：
  - 倒计时需要确认；取消时给一句鼓励。
  - 正计时直接暂停。
  - 暂停保留毫秒进度。
- 倒计时归零：显示完成，按设置播放提示音（660、880、1046 Hz 三个上行音）。
- 正计时不会自动结束。
- 重置：倒计时恢复满时长，正计时归零。
- 运行状态不保存，重启后回到空闲。

## 5. 活动模式

- 两种模式：自习、休闲。
- 影响范围：角色道具（自习时电脑打开、握笔手臂），以及表情条件规则中的对应场景开关（见第 7 节）。
- 计时进行中从自习切到休闲需要确认：
  - 确认：暂停计时并切换。
  - 取消：给一句鼓励。

## 6. 表情与编辑器

- 表情由角色包的 `expressions.json` 与用户自定义表情目录（`%APPDATA%\韵梦桌伴\custom_expressions\<角色id>\`）共同提供。
  - 一级表情：替换眼和嘴。
  - 二级表情：叠加在当前一级表情上，可替换眼嘴并加特效。
- 控制台把表情分为两组：一级表情、二级表情。
- 再点一次当前表情会回到自然表情（`neutral`，每个角色包必须有）。
- 手动选择会打断正在显示的随机表情。
- 换角色或重新载入后，已选表情不存在时回到自然表情。
- 表情选择不保存。
- 表情编辑器：
  - 从表情页进入，列出当前角色全部一级与二级表情（「内置」/「自定义」徽章及场景摘要）。
  - 新建/编辑自定义表情：选择一级或二级分类，起名字（最多 12 字、不重名），按槽位导入与角色画布同尺寸的透明 PNG（一级需眼睛+嘴巴，二级眼睛/嘴巴/特效三选一即可），立即校验尺寸并复制到用户目录保存。
  - 内置表情可编辑出现条件，不可改素材或删除；自定义表情可编辑名称、素材、条件或删除。

## 7. 随机表情、条件规则与眨眼

- 随机表情：
  - 默认开，每 120 秒抽取一个，间隔可设为 5–86400 秒。
  - 每个表情可在表情编辑器中单独配置：是否参与随机、随机持续时长（100–600000 ms，编辑器内按秒设置）、以及在「休闲」「自习」「听歌」三个场景下是否允许随机出现，支持「恢复默认条件」。
  - 活动模式、音乐状态、表情条件或间隔变化时，重新计时并清除当前的随机表情。
- 听歌打瞌睡锁定：
  - 「打瞌睡」（`doze`）的听歌随机开关永远锁定关闭；播放音乐时，手动选择的打瞌睡也不显示。
- 眨眼：
  - 间隔和闭眼时长写在角色包里。
  - 以下情况不眨眼：一级表情不允许眨眼，表情是整张动画图，二级表情替换了眼睛，或正在显示喜欢、打瞌睡。

## 8. 节拍跟随与角色动画

- 听歌且「自动跟拍」开启时：
  - 节拍锁定后按预测的拍点点头。
  - 每拍头部弹跳、歪头、缩放脉冲。
  - 节拍光环扩散，飘出音符。
- 听歌时戴上耳机。
- 待机呼吸，幅度随音量变化。
- 打瞌睡时头会下垂。
- 计时进行中显示计时钟，并带有呼吸节奏的光晕。
- 以上动作的幅度、时长、概率和图层条件都写在角色包的 `character.json` 里。

## 9. 音频同步

- 音源：
  - 系统声音：WASAPI 回环采集，只分析、不回放。可以选择输出设备，默认跟随系统默认输出。
  - 音频文件：拖到桌宠身上，支持 mp3、wav、ogg、flac、m4a、aac；循环播放，同时分析。
- 控制台音乐页：
  - 状态：未开始、连接中、同步中。
  - 读数：BPM、是否已锁拍、已跟拍次数、音量和低频电平条。
  - ×2／÷2：手动纠正倍速或半速的误锁；检测器自己跳到另一个八度时自动取消。
  - 声音来源下拉框，「刷新」重新枚举设备，「打开系统声音设置」。
- 提示：
  - 开始 3.5 秒后仍然几乎无声，提示检查播放或换设备。
  - 出错时显示中文提示：找不到设备、格式不支持、文件无法读取、其他系统错误。
- 「显示 BPM」只影响控制台显示，不影响检测。
- 节拍检测：
  - 固定 60 Hz 运行。
  - 周期范围 300–1000 ms，即 60–200 BPM。
  - 控制台每 120 ms 刷新一次读数。

## 10. 待办清单

- 清单名最多 40 字，每项最多 60 字。
- 每项可以勾选完成、编辑文字、删除；也可以添加新的一项。至少保留一项。
- 默认三项空白。
- 修改自动保存。
- 外接 Markdown 文档：
  - 支持导入已有 `.md` 清单或另存新建外置 `.md` 清单，原地绑定并自动回写。
  - 回写时保留原文件中的标题、空行与普通正文段落，仅同步首个 `# ` 标题与 `- [ ]` / `- [x]` 任务行。
  - 支持一键重新载入外部修改，或解绑切回内置清单。
  - 绑定的 `.md` 路径会保存，重启时自动读取最新内容。

## 11. 设置与持久化

| 设置 | 默认 |
|---|---|
| 背景模式与自定义背景色 | 浅色（无自定义 HEX） |
| 背景透明度与卡片透明度 | 100% / 100%（0%–100%） |
| 强调色与自定义强调色 | 樱花粉（无自定义） |
| 界面圆角 | 圆角（14px；可选关闭 0px 或自定义 0–28px） |
| 背景图片与遮罩浓度 | 无背景图（默认遮罩 60%，范围 20%–95%） |
| 控制台透明度 | 100%（40%–100%） |
| 桌宠透明度 | 100%（30%–100%） |
| 中/英文字体、字号与外部字体路径 | 中文微软雅黑 UI / 英文 Segoe UI / 13px（11–18px），无外部字体 |
| 自定义快捷键（3 全局 + 3 控制台内） | `Ctrl+Alt+C` / `Ctrl+Alt+L` / 未设置；`Space` / `Q` / `H` |
| 外接 Markdown 待办路径 | 无（内置清单） |
| 倒计时结束提示音 | 开 |
| 自动换表情 | 开，120 秒 |
| 显示 BPM | 开 |
| 自动跟拍 | 开 |
| 声音来源 | 系统默认输出 |
| 桌宠大小 | 100% |
| 全屏时隐藏 | 开 |
| 开机自动启动 | 关 |
| 角色 | `sakura` |

- 保存的内容：上表的设置、桌宠位置、计时时长与方向、各表情条件规则、待办清单。
- 自定义表情文件独立保存于 `%APPDATA%\韵梦桌伴\custom_expressions\<角色id>\`；背景图片复制于 `%APPDATA%\韵梦桌伴\background.<ext>`。
- 保存位置：`%APPDATA%\韵梦桌伴\state.json`。
  - 有变化后 500 ms 写入，先写临时文件再改名。
  - 读取时字段缺失或非法，逐字段回到默认值，不弹错。
- 设置页还有：退出、关于（MIT 许可与 Slint 致谢）。

## 12. 角色包

- 内置角色「二次元学霸少女·樱音」（`sakura`）。格式见 [角色包格式](角色包格式.md)。
- 按以下顺序查找角色目录：
  1. 环境变量 `YUME_CHARACTERS`
  2. `%APPDATA%\韵梦桌伴\characters`
  3. 程序同级的 `characters`
- 设置页可以切换角色，或「重新载入」当前角色（改了素材不用重启）。
- 角色在后台加载。加载失败时保留原来的角色并显示原因。
