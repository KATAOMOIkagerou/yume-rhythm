# Rust 独立桌面版验收记录

日期：2026-11-20。系统：Windows x64，缩放 200%，Rust 1.100.0，WebView2 157.0.4341.60。

## 白边、素材截断与透明穿透修正

此前使用 SetWindowRgn 将图层透明度变成可见窗口裁切区域，二值轮廓与半透明边缘及后续动画帧不一致，导致边缘露白、素材被裁掉。此次彻底移除可见区域裁切，命中掩码仅控制输入穿透；关闭桌宠无边框窗口的系统阴影，并保留原生、WebView2 和网页三层透明背景。素材文件未删改，UI 和原有 24 fps 动画保持一致。

此前仅检查网页截图 alpha，无法证明真实 Windows 合成效果。此次新增仅在验证模式可调用的原生检查：在桌宠下面显示两种已知底色，直接读取桌面合成像素，同时覆盖锁定／解锁。透明区域准确透出底色；393 个轮廓点分别在四种组合下与 alpha 合成结果比较，390 点各通道误差不超过 6，其余 3 点最大误差 10（0～255），通过验收容差，未发现明显白边或素材裁切。独立窗口截图可能将透明区显示成白色，因此不再以该现象单独判断原生白底。

原生命中检查通过：透明角落和图层内部空隙不命中桌宠 HWND，实体区域保留交互，锁定时整窗穿透。休闲／自习模式的椅背、人物、电脑、手臂、桌面和书本均完成加载；休闲电脑合盖、自习电脑打开属于原有设计。完整功能回归通过，59 项控件坐标与原版一致。本轮 120 BPM 信号测得 122 BPM，2.1 秒观测 51 次头部变换。

最新结果见 [透明与白边修正记录](verification/transparency-report.json)，程序大小和散列见 [build-info.json](verification/build-info.json)。下方为首次重构的历史验收记录。

## 构建和独立运行

- `npm run build` 发布构建成功，Rust 编译无警告；`npm run verify`、Rust 格式检查均通过。
- 运行程序为 `bin/桌宠节奏师.exe`，大小 2,341,888 字节，内嵌界面与默认素材。
- 将 `bin` 内容单独复制到系统临时目录 `desktop-pet-rust-EreSA9`，仅携带 EXE、素材、许可证和使用说明后启动，并完成实际功能检查。该目录不含源码、node_modules、Rust 工具或原 Electron 项目。
- 发布程序不启动 Node.js、Electron 或 Vite 服务；需要系统 WebView2 运行时。构建信息和 EXE SHA-256 见 [build-info.json](verification/build-info.json)。

## UI 对齐

使用原 Electron 程序与 Rust 程序的真实窗口提取四页控件位置；在相同初始状态下，**59 项控件的 x、y、宽度、高度最大偏差为 0 逻辑像素**。四页均无横向溢出。

桌宠为 540×590，控制台为 470×780 逻辑像素；在本机 200% 缩放下，原生窗口实际分别为 1080×1180 和 940×1560 像素。控制台内容区为 470×608 逻辑像素，四页一致。

## 范围和限制

Rust 替换了 Electron 桌面后端，并实现原生音频回环；React/CSS 界面、24 fps 动画和冻结节拍算法继续复用。该实现不是将所有界面和检测算法全部翻译成 Rust。

自动验收覆盖上表项目。托盘交互、鼠标拖动和标准全局组合键由原生库接入；未将它们计入自动通过项。本机有其他正在运行的程序占用 Ctrl＋Alt＋L 和 Ctrl＋Alt＋C，注册失败不会阻止桌宠启动；使用标准全局快捷键前应退出占用它们的旧版并重启本版。

UI 的零偏差结论适用于本机 200% 缩放下已记录的 59 项初始控件，不代表已遍历所有分辨率、缩放、输入法与音频驱动。现有默认输出设备限制保留，旧 Electron 设置不会自动迁移。此次未做原版与 Rust 版的严格内存／CPU 对照测试，不以重构语言推断性能收益。

## 重现

```powershell
npm ci
npm run verify
npm run build
npm run verify:desktop
npm run verify:saved-state
```

`verify:desktop` 会短暂播放 120 BPM 测试信号；测试数据使用独立用户目录，结束时关闭其启动的程序。通过 `PET_TEST_EXE` 可以指定复制到其他目录的 EXE；使用 `PET_REFERENCE_LAYOUT` 指向本目录的 `verification/layout-original.json`，可以重现控件坐标对比。
